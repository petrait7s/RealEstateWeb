# Real Estate Web

Premium real-estate developer site + admin CMS. Next.js 16, Tailwind 4, Framer Motion, GSAP, Lenis, next-intl, Supabase.

## Run

```bash
cp .env.example .env.local
npm install
npm run dev
```

Scripts: `dev`, `build`, `start`, `lint`, `typecheck`, `test`.

See `docs/PROGRESS.md` for build status and `docs/DECISIONS.md` for choices made.
